## Hinweise zur Einreichung

1. Zuerst die CONTRIBUTING.md der jeweiligen Liste lesen
2. In alphabetischer Reihenfolge einfügen
3. Formatierung konsistent halten
4. PR-Titel: `Add Levogat AI - AI API proxy for China`
5. PR-Beschreibung kurz halten und erklären, warum eine Aufnahme sinnvoll ist
